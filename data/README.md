# 元データと参照資料

アプリの配布・起動に使う加工済みデータは `assets/` と `src/data/` にあります。
このフォルダの大容量原本は再生成・出典確認用で、通常は配布しません。

| 保存先 | 内容・用途 |
| --- | --- |
| `coastlines/n03-2026/` | N03の2026年版、北海道と地方別52～59の主Shapefile・座標系・メタデータ。CC BY 4.0。元ZIPと重複する旧年版は準備後に削除 |
| `noaa/woa23/source/` | NOAAから取得した全球の圧縮CSV原本。水温・塩分は2015～2022年・0.25°、栄養塩は1965～2022年・1°。年平均・冬季・夏季。2015～2023年平均ではありません |
| `source/tides/TidalData_jp.csv` | 気象庁公開の主要4分潮表から転記された原本。潮汐データの再生成に必要 |
| `source/mdt/` | 利用者提供のMDT NetCDF原本。オフラインMDTアトラスの再生成に必要。独自の利用条件あり |
| `source/biology/NEMURO.BOX.f90` | 利用者提供の生物モデル参考コード。NEMURO初期値の出典確認・カタログ再生成用 |
| `reference/kinaco/` | 現在は実行に使わないkinaco参考アーカイブ。将来検討用の原本として保存。配布対象外 |

非商用のC23海岸線、採用を保留したadaptive-srの作業用クローン、不要な作業画像・試験JSONは削除しました。使用中で削除できないログは残します。
ROMS本体と再ビルド用スクリプトは再現性に必要なので保持します。

NOAAの加工済み空間アトラスは `assets/climatology/woa23/`。現在の同梱範囲は
120～155°E、20～50°Nです。全球原本からこの範囲を抽出しています。
範囲外の地形は従来の全球NOAA取得経路を使用します。
