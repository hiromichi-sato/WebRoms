# READMEの計算例

READMEの結果図は、実際のブラウザー版ROMSで計算した理想化実験です。画像生成AIによる海洋場や、手描きの架空コンターではありません。

## 条件

| 項目 | 設定 |
| --- | --- |
| 地形 | 同梱の理想化した湾。実在の湾の観測再現ではない |
| 格子 | 24×20、鉛直8層、水平間隔2,000 m |
| 水深 | 40〜120 m |
| 初期状態 | 模擬夏季成層、表面26℃／底面12℃、表面塩分32／底面35、混合強度10% |
| 風 | 10 m風速6 m/s、南へ吹く一様風（吹いていく方位180°） |
| 回転・混合 | 北緯35°のf平面、GLS鉛直混合 |
| 生態系 | NPZD、模擬夏季分布、同梱の反応係数 |
| 境界 | 四辺閉鎖。河川・潮汐・外部海面高度・海面熱交換なし |
| 積分 | 10秒×8,640ステップ＝24モデル時間 |
| 図の色範囲 | 有効値の最小〜最大。主図と断面は独立した範囲 |

[再実行用条件JSON](examples/readme-wind-npzd.json) を同じ配布版のWebROMSで読み込めます。読み込みと実行の操作は [利用ガイド](USER_GUIDE.md) を参照してください。スクリプトは `scripts/capture-readme-results.mjs` です。

## 図をどう読むか

![水温と流速、鉛直断面](images/readme/results-temperature.png)

左は表層の水温と水平流速ベクトルです。右は主図のピンク線を通る鉛直断面です。温度の鉛直構造と、風・回転・地形のある条件下で計算された流れを同時に観察できます。

![植物プランクトン濃度と鉛直断面](images/readme/results-biology.png)

同じ実験の植物プランクトン濃度です。単位は窒素濃度（mmol N/m³）で、画像のカラーバーを参照してください。NPZDの反応・輸送・沈降を含む出力であり、観測された植物プランクトン量やその炭素量を直接表すものではありません。

## 注意点

- 24時間の計算例で、定常到達の主張はしていません。
- 風なしとの対照実験や観測検証は、この図には含まれません。特定の現象の原因や再現精度を、この図だけで断定しないでください。
- 3Dの鉛直方向は強調されています。主図と断面の色範囲は独立しています。
- ソフトウェアの実装・配布版が変わると、表示や数値結果が変わる場合があります。

## 概念図

READMEの構成・ワークフロー・ファイル共有図は、編集可能なSVGから生成したPNGです。計算結果ではなく製品の説明図です。元データは `docs/images/readme-*.svg`、再生成は `scripts/render-readme-figures.mjs` にあります。
